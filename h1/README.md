# H1 - Análisis de Algoritmos

// A) ¿O de qué?
// O(1) - Tiempo Constante. Acceder a un índice específico de un arreglo toma el mismo tiempo sin importar el tamaño de la lista.

// B) ¿O de qué?
// O(n) - Tiempo Lineal. Búsqueda secuencial (recorre la lista elemento por elemento). En el peor de los casos, revisa todos los elementos.

// C) ¿O de qué?
// O(n^2) - Tiempo Cuadrático. Tiene dos bucles anidados (uno dentro de otro). Si 'n' crece, el tiempo se multiplica por sí mismo.

// D) ¿O de qué?
// O(log n) - Tiempo Logarítmico. Es una búsqueda binaria (divide el problema a la mitad en cada iteración). Es muy eficiente.
